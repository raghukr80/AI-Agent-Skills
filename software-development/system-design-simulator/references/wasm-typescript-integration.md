# WASM Module TypeScript Integration

## Problem: TypeScript can't type-check WASM `.js` glue code

When importing wasm-pack generated `.js` glue code in a TypeScript file, the compiler fails:

```
error TS2307: Cannot find module '../../wasm/simulationController' or its corresponding type declarations.
```

This happens because:
1. The `.js` file is generated by wasm-pack and has no TypeScript types
2. TypeScript's `moduleResolution: "bundler"` can't resolve `.js` imports from `.ts` files without proper declarations

## Solution

### 1. Add `// @ts-nocheck` to the WASM module file

At the top of `simulationController.ts`:

```tsx
// @ts-nocheck
// WASM Simulation Controller
import init, { SimController } from './sim_engine.js'
```

This tells TypeScript to skip type-checking for this file entirely.

### 2. Add a type declaration file

Create `simulationController.d.ts` alongside the `.ts` file:

```ts
export interface DiagramData {
  nodes: any[]
  edges: any[]
}

export interface SimulationResult {
  systemMetrics: {
    totalRps: number
    p99: number
    errorRate: number
    bottleneckCount: number
    history: any[]
    componentMetrics: Record<string, any>
  }
  nodeMetrics: Record<string, any>
}

export declare class SimulationController {
  init(diagram: DiagramData): Promise<void>
  start(): void
  pause(): void
  resume(): void
  stop(): void
  step(): SimulationResult | null
  setSpeed(multiplier: number): void
  getMetrics(): SimulationResult | null
}

export declare const simulationController: SimulationController
```

### 3. Fix `.gitignore` in wasm directory

The wasm directory's `.gitignore` had `*` which ignored ALL files. Replace with whitelist:

```
*
!.gitignore
!simulationController.ts
!simulationController.d.ts
!sim_engine.d.ts
!sim_engine_bg.wasm.d.ts
```

### 4. Keep `vite.config.js` in sync with `vite.config.ts`

If both files exist, Vercel may pick up the `.js` version. Make sure both use ESM-compatible imports:

```js
import { fileURLToPath, URL } from 'url'
// NOT: import { resolve } from 'path'
```

## Key Pitfall: `.gitignore` blocking source files

The wasm directory's `.gitignore` pattern `*` was too broad — it ignored ALL files including the simulation controller source that should be tracked in git. The fix is to use a whitelist pattern that explicitly un-ignores the source files while still ignoring build artifacts.
